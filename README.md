# HackFlow by Megalo04

**HackFlow** es una herramienta de pentesting y hacking ético diseñada para automatizar y simplificar tareas comunes en entornos Linux.

---

## Características principales

- Instalación automática de dependencias según el entorno.  
- Menú interactivo y colorido para facilitar la selección de tareas.  
- Automatización de comandos complejos: escaneo de puertos, reverse shells, listeners, etc.  
- Enfoque en el aprendizaje responsable y la ética en seguridad informática.

---

## Instalación

Clona el repositorio:

```bash
git clone https://github.com/tu_usuario/HackFlow.git
cd HackFlow
```
Instala las dependencias:

```bash
pip install -r requirements.txt
```

Uso
Ejecuta la herramienta desde la terminal:

```bash
python hackflow.py
```
Sigue el menú para elegir las acciones que deseas realizar.
